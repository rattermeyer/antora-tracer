# Self-Traceability Example

This example demonstrates the Antora Tracer extension tracing its own requirements, architecture, and tests.

## What's Here

| File | Content | Items |
|------|---------|-------|
| `requirements.adoc` | 36 requirements extracted from OpenSpec specs | 36 `[item, role=requirement]` |
| `architecture.adoc` | arc42-style architecture with PlantUML diagrams | 4 `[item, role=architecture]` |
| `test-plan.adoc` | Test coverage mapping to REQ-IDs | 7 `[item, role=test]` |
| `traceability.yml` | Custom domain model: requirement, architecture, test | — |
| `traceability/` | Pre-generated matrices and Neo4j export | — |

## Pre-generated Output

The `traceability/` directory contains pre-generated output from `run-example.js`:

- `matrix-requirements-coverage.html` — Requirements × Architecture × Test matrix
- `matrix-requirements-coverage.csv` — Same data in CSV format
- `nodes.csv`, `relationships.csv` — Neo4j CSV export

These files are included as static pages in the Antora site and linked from the navigation.

## How to Run

[source,bash]
----
cd antora-asciidoc-tracing
npm run build
node examples/run-example.js
----

This processes all three content files together, generating:
- 48 items (36 requirements, 4 architecture, 7 tests)
- 82 relationships (43 architecture→requirement, 39 test→requirement)
- 0 validation errors

Output is written to `examples/modules/ROOT/pages/traceability/`.

## Domain Model

Three roles with directed relations:

[source]
----
  architecture ──addresses──▶ requirement
  test ──────────verifies───▶ requirement
  test ──────────validates──▶ architecture
----

One matrix: `requirements-coverage` (rows: requirement, columns: architecture + test).

## Antora Site

To build the full Antora site with navigation, you need a UI bundle.
The playbook references the default Antora UI from GitLab.

First, cache the UI bundle (one-time download):

[source,bash]
----
npx antora antora-playbook.yml --ui-bundle-url https://gitlab.com/antora/antora-ui-default/-/jobs/artifacts/HEAD/raw/build/ui-bundle.zip?job=bundle-stable
----

Then build:

[source,bash]
----
npx antora antora-playbook.yml
----

Or, if the GitLab URL doesn't work, download the bundle manually and
update the `ui.bundle.url` in `antora-playbook.yml` to a local path.

The built site (`public/`) includes the traceability matrix accessible
from the navigation under "Traceability Matrix".

## To render PlantUML diagrams

Install asciidoctor-kroki:

[source,bash]
----
npm install asciidoctor-kroki
----

The architecture diagrams require a Kroki server (default: https://kroki.io).
