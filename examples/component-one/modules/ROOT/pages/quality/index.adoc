= Quality Attributes

This section documents the quality attributes (non-functional requirements) that shape the Antora Tracer extension. Each quality attribute follows the https://quality.arc42.org/[arc42 Quality Model] format: Context, Trigger, Acceptance Criteria.

* xref:quality/zero-operational-overhead.adoc[Zero Operational Overhead] — No external services, minimal dependencies
* xref:quality/configurable-without-code.adoc[Configurable Without Code Changes] — Roles, relations, and matrices in YAML
* xref:quality/fail-fast-diagnostics.adoc[Fail-Fast with Clear Diagnostics] — Typo detection, file/line/item-IDs in errors
* xref:quality/no-side-effects.adoc[No Side Effects on Source Files] — All transformations in-memory, source files never modified
* xref:quality/pdf-compatibility.adoc[PDF Compatibility of Generated Output] — Standard AsciiDoc output for cross-backend rendering
* xref:quality/testability-by-design.adoc[Testability by Design] — Dependency injection, isolated test files, fast feedback
* xref:quality/platform-stability.adoc[Platform Stability and Longevity] — ESM, TypeScript strict, Node.js 20+, zero-framework
* xref:quality/performance.adoc[Query and Indexing Performance] — O(1) lookup, reverse indexes, BFS, caching with invalidation
