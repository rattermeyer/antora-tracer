= Antora Tracer — Project Site

Welcome to the project site for the *Antora Tracer* extension — a role-based traceability extension for Antora/AsciiDoc.

== Where to start

Pick the section that matches what you need:

* xref:tutorial/getting-started.adoc[Tutorial: Getting Started] — follow a step-by-step guide from zero to a working traceability setup
* xref:how-to/new-project-setup.adoc[How-to Guides] — solve a specific task (set up a project, define a custom domain model, export to Neo4j, troubleshoot issues)
* xref:reference/item-macro.adoc[Reference] — look up macro syntax, CLI commands, configuration options, or the API
* xref:explanation/traceability-model.adoc[Explanation] — understand the traceability model, processing pipeline, architecture, and design decisions

== What's here

This site follows the https://diataxis.fr[Diátaxis] documentation framework:

[width=100%, cols="25,40,35"]
|===
| Section | Answers the question | Example pages

| Tutorial
| "Can you teach me to…?"
| Getting Started

| How-to Guides
| "How do I…?"
| Set up a project, Define a domain model, Export to Neo4j

| Reference
| "What does X do?"
| Item macro syntax, CLI commands, Configuration options, API

| Explanation
| "Why does it work that way?"
| Traceability model, Processing pipeline, Architecture, ADRs
|===

A fifth section, *Self-Traceability*, demonstrates the extension applied to its own development — requirements, use cases, test plan, and dashboard — traced against each other using the same `[item]` macros.

== Generated Traceability

The traceability matrix is pre-generated by `examples/run-example.js` and included directly in the site:

* xref:ROOT:attachment$traceability/matrix-usecases-to-requirements.html[Use Cases → Requirements] — Which requirements each use case leads to
* xref:ROOT:attachment$traceability/matrix-requirements-to-design.html[Requirements → Architecture] — Which architecture sections address each requirement
* xref:ROOT:attachment$traceability/matrix-requirements-to-tests.html[Requirements → Tests] — Which tests verify each requirement

To regenerate after changing content:

[source,bash]
----
cd antora-asciidoc-tracing
npm run build
node examples/run-example.js
----

This produces 112 items, 118 relationships, and 0 validation errors across the content files.
