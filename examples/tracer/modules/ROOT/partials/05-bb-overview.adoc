|===
| Component | Responsibility | Key dependencies

| CLI
| Standalone command-line entry point for processing, matrices, validation, export, and ID allocation.
| `RequirementsTraceabilityExtension`, `ConfigLoader`

| `AntoraTraceabilityExtension`
| Antora entry point. Hooks site-generation events, loads configuration, and orchestrates the core API against the content catalog.
| `RequirementsTraceabilityExtension`, Antora APIs

| `RequirementsTraceabilityExtension`
| Public core API. Owns the graph and delegates parsing, matrix generation, and export.
| `DocumentParser`, `TraceabilityGraph`, `MatrixGenerator`, `Neo4jExporter`, `ConfigLoader`

| `ConfigLoader`
| Loads and validates built-in presets and user YAML configuration.
| Preset YAML files and user configuration

| `DocumentParser`
| Extracts traceable items and relationships from AsciiDoc.
| `ConfigLoader` (optional role and relation validation)

| `TraceabilityGraph`
| In-memory graph with validation, relationship indexes, query, diff, and visualization support.
| `ConfigLoader` (optional relation rules)

| `MatrixGenerator`
| Generates configured matrices in HTML, CSV, or JSON formats.
| `TraceabilityGraph`, `ConfigLoader`, `TemplateRenderer`, `LinkResolver`

| `TemplateRenderer`
| Renders HTML matrices from Mustache templates.
| Built-in or user templates

| `LinkResolver`
| Resolves links from matrix cells to item source pages.
| None

| `Neo4jExporter`
| Exports graph data to Neo4j CSV and Cypher files.
| `TraceabilityGraph`, `ConfigLoader`
|===
