[#REQ-109, item, role=requirement, title="Circular reference detection in graph validation"]
--
The system SHALL detect circular references in the traceability graph during validation.
A circular reference is a cycle in the directed relationship graph (e.g., A → B → A, or A → B → C → A).
Self-referencing relationships (A → A) SHALL also be detected as cycles.
Auto-generated inverse relationships SHALL be skipped during cycle detection to avoid false positives.
Relationships marked as bidirectional SHALL also be skipped during cycle detection.
