== Quick Start

To see the extension in action:

. Install dependencies:
+
[source,bash]
----
cd example-site
npm install
----

. Build the site:
+
[source,bash]
----
npx antora antora.yml
----

. Open the site:
+
[source,bash]
----
open _site/index.html
----

That's it! The extension will automatically:

* Parse all `[req]`, `[imp]`, `[test]`, and `[doc]` block macros
* Extract inline relationship macros (satisfies, implements, tests, etc.)
* Build a traceability graph
* Generate traceability matrices in HTML and CSV formats
* Create a coverage report

== Requirements Defined in This Site

This site demonstrates 4 example requirements:

* EXAMPLE-001: Welcome Page
* EXAMPLE-002: Requirement Definition
* EXAMPLE-003: Traceability Linking
* EXAMPLE-004: Matrix Generation

Each requirement is implemented by one or more architecture components, creating a complete traceability chain.

== Architecture Components

The extension's architecture is documented in the Architecture section, with each component linked to the requirements it satisfies or implements:

* **AsciiDoc Processor**: Parses AsciiDoc content (satisfies EXAMPLE-002)
* **Traceability Graph**: Manages relationships (satisfies EXAMPLE-002, implements EXAMPLE-003, EXAMPLE-004)
* **Matrix Generator**: Creates matrices (implements EXAMPLE-004)
* **Antora Extension**: Integrates with Antora (implements EXAMPLE-001)

== Troubleshooting

If you encounter issues:

* Ensure Node.js 14+ is installed
* Ensure npm is installed
* Run `npm install` from the example-site directory
* Check the console output for errors during the build
* Verify that the extension is properly referenced in package.json

== About This Extension

The Requirements Traceability Extension adds requirements traceability capabilities to Antora/AsciiDoc:

* Define requirements, implementations, tests, and documents using custom block macros
* Establish relationships between elements using inline macros
* Generate traceability matrices in HTML and CSV formats
* View coverage reports showing implementation and test status

For more information, see the User Guide and Developer Guide in the main repository.
