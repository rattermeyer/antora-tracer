## Why

Version 0.10.0 was released on 2026-07-30. Since then, several features and fixes have accumulated: bidirectional graph traversal in `toDot`, Lunr item-anchor indexing, landing page conemso theme alignment, use-case-engineering skill, and CI fixes. These warrant a new minor release to make them available to npm consumers.

## What Changes

- Bump version from `0.10.0` to `0.11.0` in `package.json`
- Update `CHANGELOG.md` with all changes since 0.10.0
- Create git tag `v0.11.0`
- Push tag and publish to npm

## Capabilities

None — all capability changes were delivered in previous changes and already synced to main specs.

### Modified Capabilities

None.
